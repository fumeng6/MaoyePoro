# 输入输出格式

用途、安装和最小示例见[README](../README.md)，完整教学见[用户手册](用户手册.md)，三份合成输入位于 `cases/`，本页集中说明格式选择、文件操作及读写测量。

采用 **TOML 配置物理问题，用 JLD2 保存完整计算结果，用 Julia 数组开展分析**。
需要与其他软件交换数据时，再显式导出文本时序和快照。
求解器的频谱及内核工作区在内存中，完整归档用于保存结果；不需要用户管理中间频谱文件。

## 从一个算例开始

安装可执行程序后，在包含输入文件或示例的目录直接运行：

```sh
myporo cases/constant_injection.toml --check
myporo cases/constant_injection.toml --output results/constant_injection --format both --julia-args -t4
mycfs stress.toml
```

安装与平台要求见[可执行程序说明](用户手册.md#installation)。可执行程序和源码使用相同输入、结果格式及数值选项。下面保留源码调用方式：

```powershell
$env:OPENBLAS_NUM_THREADS = "1"
julia --threads=4 --project=. maoyeporo.jl cases/constant_injection.toml --check
julia --threads=4 --project=. maoyeporo.jl cases/constant_injection.toml --output results/constant_injection --format both
```

带 `--check` 的命令只读取并检查输入、实际分层和深度网格，显示模型规模及数值设置；不计算场，也不判断收敛。
最后一条命令完成求解，将完整结果写入 `results/constant_injection/result.jld2`。

这里的两种调用均用 `--format both` 同时导出文本时序和快照；省略时默认只保存 JLD2。路径相对于终端当前目录，CSV 历史的相对路径则按其 TOML 所在目录解释。省略 `--output` 时写入输入旁的 `results/<输入名>/`，同名文件会被覆盖。

命令行可选项：

| 选项 | 用途 |
| --- | --- |
| `--template [FILE]` | 创建带中文注释的待填写 TOML；省略文件名时为当前目录的 `case.toml`，拒绝覆盖已有路径 |
| `--output DIR` 或 `-o DIR` | 指定输出目录 |
| `--format jld2`、`text`、`both` | 单文件完整结果、文本交换文件，或两者同时保存 |
| `--max-frequencies N` | 指定频率容量，至少 512，且为 2 的幂 |
| `--image-factor X` | 时间周期延拓响应的衰减因子，默认 0.001 |
| `--serial` | 关闭场量和可选等效源计算的频率并行 |
| `--diagnostics` | 单独保存 `diagnostics.txt` 并显示详细计算进度 |
| `--quiet` | 关闭详细进度消息，仍保留简短状态、保存路径和科学警告 |
| `--check`、`--help` | 检查配置，或显示帮助 |
| `--version` | 显示 MaoyePoro 版本；`myporo` 和 `mycfs` 均支持 |

求解时只接受一个 TOML 输入文件，输出目录及数值运行设置均用上述命名选项指定。
频率容量和 `image_factor` 的数学定义见[使用说明](输入输出格式.md)。

可用 `myporo --template case.toml` 生成待填写配置，源码调用为 `julia --project=. maoyeporo.jl --template case.toml`。目标父目录须已存在；命令仅创建文件，不求解，也不与求解选项混用。模板含物理含义和单位，必填标量以 `""`、必填数组以 `[]` 留空；数值字段填写时去掉引号，填写后才能运行 `--check` 或求解。

源顶底深度、源半径和时间窗必须为有限数值；`inf`、`-inf` 和 `nan` 不能作为这些物理输入。

## TOML 输入

[constant_injection.toml](../cases/constant_injection.toml) 是均匀全空间中的恒定注水示例。
TOML 使用命名字段，不需要填写行数、等距开关或源类型数字码。

模拟输入和 JLD2 结果的文件结构版本均为 `schema_version = 2`；库仑应力 TOML 的结构版本为 1。文件结构版本独立于程序版本号。

| 配置部分 | 主要字段 |
| --- | --- |
| `[source]` | `kind`、`top_m`、`bottom_m`、`radius_m`，历史用 `times_s`＋`values` 或 `history_file` |
| `[receivers]` | `radii_m`、`depths_m`，按升序给出数组 |
| `[time]` | `window_s`、`samples` |
| `[medium]` | `surface`：`"fullspace"`、`"drained"` 或 `"sealed"` |
| `[[medium.nodes]]` | `depth_m`、`shear_modulus_pa`、`poisson`、`undrained_poisson`、`skempton`、`diffusivity_m2_s` |
| `[numerics]` | 可选 `accuracy`，默认 0.05 |
| `[output]` | 可选文本分量、快照、等效源和 `diagnostics` 设置 |

`source.kind` 决定历史 `values` 的物理量及单位：

| `kind` | 物理量 | `values` 单位 |
| --- | --- | --- |
| `"force"` | 地表或地下施加的竖向总力 | N |
| `"matrix_volume"` | 已知排水体积应变在源区的积分 `Vd` | m³ |
| `"injection_rate"` | 每秒注入或抽出的流体体积，负值表示抽水 | m³/s |
| `"injection_moment"` | 源区平均孔压乘源体积，即孔压体积积分 | Pa·m³ = N·m |

`injection_moment` 是上游程序对孔压体积积分的命名；它规定源区平均孔压，不是某个井壁点的压力。`matrix_volume` 给定预先求得的排水体积变化 `Vd=∫源区 εd,vol dV`，仅计算由它引起的孔压与附加变形，输出不含原排水位移、应变和应力。完整外载响应需另外叠加已知排水场；竖向加载也可直接使用 `force` 求耦合响应，定义见[科学约定](MaoyePoro原理.md)。

所有时刻为秒、距离为米，深度向下。`times_s` 和 `values` 长度必须一致，首时刻为 0。
**重复时刻保留阶跃，窗外未来节点保留跨窗斜坡；模型重复深度保留界面两侧。**
读取和写入不会排序、去重、截断或补入这些节点。非零首值表示零时刻加载阶跃；
也可像示例一样用重复的 `0.0` 明确写出阶跃前后的值。

长历史可改为 `history_file="injection_history.csv"`，与内嵌数组互斥。文件首行为 `time_s,value`，每行一对时间和源值，单位沿用 `source.kind` 的 SI 定义。相对路径按 TOML 所在目录解析。CSV 写法及时间节点含义见[用户手册](用户手册.md#long-history)。外部文件只改变存放方式，不会自动抽稀或减少长历史叠加成本。

可选输出配置例如：

```toml
[output]
fields = ["uz", "pp"]
snapshot_times_s = [500000.0, 1000000.0]
compute_equivalent = true
diagnostics = false
```

`fields` 只选择文本时序导出的分量；求解及 JLD2 仍保存全部十类场，以保留后续分析能力。
快照可省略文件名，程序自动生成 `snapshot_0001.dat` 等名称。
需要指定文件名时，可在 `[output.field_files]` 中按分量名称设置，例如 `pp = "pressure.dat"`；未指定的分量使用 `<分量名>.dat`。
快照及等效量文件名可用 `snapshot_files` 和 `equivalent_filename` 设置。输出目录中的 `diagnostics.txt` 专用于数值诊断，不能用作物理结果文件名。未知键或物理名称会报错，避免拼写错误静默启用默认值。

求解运行设置由命令行或 Julia 关键字参数传入。

`diagnostics` 默认为 `false`。设置为 `true` 或使用命令行 `--diagnostics` 后，各种输出格式都会额外生成一个独立的 `diagnostics.txt`，记录各接收点组的采样、求积和频率收敛细节及可选等效源诊断。详细信息不写入主结果归档。重新向同一目录写出结果时，关闭诊断会移除该目录中先前生成的 `diagnostics.txt`，避免把两次计算的信息混用。

默认终端显示简短状态、保存路径及科学警告；开启诊断后显示详细进度。`--quiet` 只关闭进度，不影响文件内容或警告。所有模式都执行相同的收敛检查，计算精度、物理结果和数值上限不随诊断开关改变。

保存或修改输入参数后，可直接写成 TOML：

```julia
using MaoyePoro
c = read_input("cases/constant_injection.toml")
write_input("results/constant_injection.toml", c)
```

若希望同时导出独立历史表，可用 `write_input("cases/run.toml", c; history_file="data/history.csv")`，分别生成 `cases/run.toml` 和 `cases/data/history.csv`。默认仍保存内嵌数组。

## 保存、读取和重新导出

Julia 中可按需决定何时写文件：

```julia
using MaoyePoro
c = read_input("cases/constant_injection.toml")
r = solve(c)                         # 结果在内存中，不自动生成文件
save_result("results/run01.jld2", r)
r = load_result("results/run01.jld2")
write_outputs(r; output_dir="results/run01_text", format=:text)
```

JLD2 保存原输入、实际离散模型和网格、时间和接收坐标、全部十个场分量、单位、轴顺序、简短计算状态 `status`、
可选等效源及其瞬时流体脉冲体积，以及实际求解设置和程序/Julia 版本。场保持 Float64，物理奇性的 `Inf`、
未定义值 `NaN` 和微弱分量不会被裁零。`r.settings.max_frequencies` 是频率容量，
实际使用的频点和逐组误差见开启诊断后生成的 `diagnostics.txt`。
若等效源包含理想阶跃脉冲，脉冲时刻和体积见 `r.equivalent_impulses`，单位分别为 s 和 m³；文本输出始终在 `simulation_info.txt` 中记录这些脉冲。
不能只积分节点速率来恢复这部分注入量。

`r.status.field_converged` 表示全部接收点组满足三个数值截断判据；`equivalent_converged` 表示等效源满足其判据，未计算时为 `nothing`；`singular_samples` 表示场量或等效源中存在理想阶跃产生的无穷样点。简短状态属于解释结果所需的信息，始终保存。

`solve` 和 `run_simulation` 返回的内存结果始终保留 `r.diagnostics` 和 `r.equivalent_diagnostics`，无需为文件输出开关重复求解。可对内存结果调用 `write_outputs(r; output_dir="results/run01", diagnostics=true)` 在保存结果时生成独立的详细报告。`load_result` 读取主归档后，`r.diagnostics` 为空，`r.equivalent_diagnostics` 为 `nothing`；查看收敛摘要用 `r.status`。完整报告应在求解时保存，主归档不能恢复已经省略的详细记录。

`save_result(path, r; compress=true)` 可启用无损压缩，压缩与读取的耗时取决于数据。
默认不压缩。JLD2 是项目的直接依赖，TOML 来自 Julia 标准库。
源历史 CSV 和文本交换由项目的读写函数处理，不需要另装表格或存储依赖。

归档保存完成后的物理结果和简短状态，不保存逐频率计算进度。`load_result` 用于重新分析及导出，
不表示恢复尚未完成的计算或断点续算。

`run_simulation` 将求解与保存合在一起：

```julia
r = run_simulation("cases/constant_injection.toml";
    output_dir="results/constant_injection", format=:both)
r.paths  # 生成的文件路径
```

未指定输出目录时，TOML 在输入文件旁的 `results/<输入文件名>/` 中生成 `result.jld2`。
内存输入 `run_simulation(c)` 和 `write_outputs(r)` 默认保存到 `results/simulation/result.jld2`。
需要文本时显式指定 `format=:text` 或 `:both`。重复使用同一目标路径会覆盖原文件；不同实验应使用不同目录或归档名。

## 按物理量和时间取结果

完整数组 `r.data` 的顺序为 `time × radius × depth × component`。
常用分析可直接按分量名称读取：

```julia
pressure = field(r, :pp)       # time × radius × depth，单位 Pa
trace = pressure[:, 1, 1]      # 第一距离、第一深度的时序
s = snapshot(r, 50000.0)      # time 以秒给出
s.data                        # radius × depth × component
s.r; s.z; s.components; s.units
```

`field` 返回原数组的视图，修改它会修改 `r.data`；需要独立副本时使用 `copy(field(r, :pp))`。
快照精确命中保存时刻时也返回视图。真正位于两个保存时刻之间的时间会生成线性插值的新数组，
不会按容差吸附到附近节点。非有限端点不能作可信的线性插值，程序会明确报错；
可选保存时刻，或使用具有物理依据的有限上升时间重新计算。

只需一个场时，可不加载其余九场：

```julia
p = read_field("results/run01.jld2", :pp)
p.time; p.r; p.z; p.unit
p.data  # time × radius × depth
```

按物理坐标查询已有归档可直接用 `sample_field(path, :pp; r=...,z=...)`，需要的场和查询元数据会一起读取；`strain_tensor` 只加载四个必要应变分量。点集、平面、曲面、时间段和方向约定见[场查询](用户手册.md#field-query)。
时间插值不会跨源历史的实际变化点，避免把加载后的响应插到加载开始前。

## 两个参数案例

复制输入再改参数即可开展参数扫描：

```julia
using MaoyePoro
base = read_input("cases/constant_injection.toml")
for (name, rate) in (("q001", 0.01), ("q002", 0.02))
    c = PoroelasticInput(base; sinj0=[0.0, rate, rate])
    r = solve(c)
    save_result(joinpath("results", "sweep", name * ".jld2"), r)
end
```

`PoroelasticInput(base; kwargs...)` 验证新参数，并复制向量和矩阵；修改新对象的历史、接收点或模型不会改动 `base`。
例如 `r=collect(0.0:250.0:2000.0)` 可直接生成等距接收点。
参数变化仍须满足[科学约定](MaoyePoro原理.md)和[使用说明](输入输出格式.md)中的源几何、介质及数值要求；
输入格式和保存方式的便利不代替对每个科学案例的收敛判断。

## 数值诊断

耦合孔隙弹性响应通过拉普拉斯逆变换，由复频率域响应求时间响应。整个介质为纯排水弹性且输入为竖向力时，准静态空间响应与频率无关，程序直接乘原始力历史；此时 `method=:static_elastic`，频率数量和频率误差均为零。均匀半空间地表抛物力盘的地表场使用 Boussinesq 解析积分，波数数量也可为零；地下接收点仍检查空间积分精度。

内存结果的 `r.diagnostics` 每个距离分组一条；开启诊断后，这些记录逐项写入 `diagnostics.txt`。记录包含实际 `effective_radius`、`differential_order`、`dk`、波数数量、频率数量及三个判据：

- `sampling_converged`：Hankel 路径实际将 dk 减半后，各接收点、各分量的时序变化是否不超过 `accuracy/4`。全部十场使用源体积积分时，误差来自求积阶数加密，不再重复与 dk 无关的计算；此项为 true，`sampling_error=0`、`dk=0`。
- `wavenumber_converged`：空间求积误差按真实源历史加权后，时序误差估计是否不超过 `accuracy/4`，且估计高频渐近系数所用的空间积分、源区孔压归一化积分满足相应判据。该字段同时记录 Hankel 积分和源体积积分的空间求积状态。
- `frequency_converged`：实际将频率数量加倍后，时序变化及两组高频渐近系数得到的时序差是否均不超过 `accuracy/4`。

任何 false 都应查看具体案例，不把达到数组上限写成收敛。这些是算法的数值截断判据，不能解释为所有输出的严格误差界。
输入 `accuracy` 也不包括模型不确定性、梯度分层误差、有限圆柱近似或现场参数误差。
`r.settings` 保存实际频率容量、`image_factor` 及并行设置，归档读回后仍可查看。
`effective_radius` 记录参与响应积分的源半径，等于输入 `sradius`；改变接收网格不改变物理源。

误差用同一接收点、同一分量的全时段峰值归一；由边界条件或精确对称性确定为零的量按相应解析关系处理，不能混合不同单位或将零量的舍入误差作为相对误差。
`sampling_error`、`frequency_error`、`asymptotic_error` 和 `wavenumber_error` 保存对应数值。
`table_samples` 是最大缓存表中的波数采样点数，包括估计高频渐近系数时使用的采样点。
`wavenumber_samples` 是计算时间响应所用频率点中最大的波数采样数量（各分开积分部分取最大值）；`kmax` 记录最大的已采样波数，单位为 m⁻¹。均匀积分中它也是截断上限，映射自适应求积则覆盖半无限区间。全部十场使用源体积积分时，两者为零。
`source_volume_samples` 记录单频最终阶数的源点数乘接收位置数，`adaptive_samples` 记录单频已采用的自适应波数核采样数量，均取时间响应所用频率点中的最大值，不是各频率累计数量。
`spatial_integration` 区分 `:source_volume`、`:hankel` 与 `:split_hankel`。源半径、源历史及物理定义不随方法改变。
均匀积分的尾估计来自相邻两次范围加倍的积分增量；源体积积分取相邻 Gauss 阶数差；映射求积取局部 8/16 点 Gauss 差与两种映射尺度的差。它们均为误差估计，并非严格数学上界。
分层流体源的均匀直接场与界面修正分别积分时，两部分各分配一半绝对容差，误差估计相加。直接场满足远离源体的距离条件时，也可用源材料全空间的源体积积分；源归一化仍使用实际分层模型，通量转换仍使用实际接收层材料。若全部接收深度均在源深度区间外，按最小竖向间隔 `g` 仅在 `10/(g*dk)≥2048` 时尝试源积分，粗网格保留指数衰减谱的便宜积分。未满足精度要求则使用原直接场积分。源与界面有正距离、`(最大接收半径+源半径)/源界面最短距离≤8`、`Re(s)>0`，且预计均匀修正需要至少 2048 点时，尝试映射自适应 Gauss；不收敛则回到原积分。
均匀全空间流体源的全部接收点离圆柱源体至少 `max(源半径,源长/2)` 时，十场均改用非振荡源体积积分，比较 4、8、16、32、64 阶结果。近源及源内点继续使用 Hankel 表达。类型 1/2/3 流体源且同组接收点全部严格位于源外时，即使不满足上述距离条件，孔压及 Darcy 通量仍使用源体积积分，避免振荡相消淹没微弱响应。这些源积分点不计入 `wavenumber_samples`。
埋藏零厚度力盘的零阶 Hankel 积分以六段 16/32 点 Gauss 求积计算 `[0,6dk]`，两规则之差计入空间误差，后续保留原网格尾项和步长加密检查。波数表达到容量后，继续减小 dk 会降低可覆盖的最大波数，不能把加密次数本身当作精度改善。

`raw_tail_failures` 统计实际时域计算使用的频率点中，空间求积未满足各自误差限值的次数。最终检查使用这些实际空间误差经源历史加权后的总时序误差估计，
因此该计数非零与最终 `wavenumber_converged=true` 可以同时成立；单个频率下波数积分的相对尾部增量，不能单独用来判断时间响应是否收敛。
高频渐近拟合的空间状态则另行检查并记录。

默认频率容量为 `nextpow(2,max(nt,8192))`。通常从256到512个频率开始比较，达到判据即停止，
不会每次计算8192个频率。可显式设置 `solve(c;max_frequencies=16384)` 或
`run_simulation(path;max_frequencies=16384)`；该值必须是至少512的2次幂。
命令行使用 `--max-frequencies 16384`，例如 `julia --project=. maoyeporo.jl input.toml --output output_directory --max-frequencies 16384`。
提高频率容量保留同一物理问题和 accuracy，并会增加时间、内存开销。波数表未达到样点上限时，步长减半会相应增加表长以保持波数覆盖范围；
也可在固定 dk 下扩展范围，最多 524288 个样点。达到该上限后，继续减小 dk 会缩小覆盖范围；未满足判据时保留 false 和警告。

离散频率的拉普拉斯逆变换相当于对时间响应作周期延拓，后续周期的响应可能叠入所求时间窗，造成混叠误差。`image_factor` 控制这种混叠的指数衰减，默认值为 0.001。Julia 中可写
`solve(c;image_factor=0.001)` 或 `run_simulation(path;image_factor=0.001)`；命令行使用命名选项，
例如 `julia --project=. maoyeporo.jl input.toml --output output_directory --max-frequencies 4096 --image-factor 0.001`。
实际值保存于诊断。常规反演定义为 `image_factor=exp(−α_L/df)`，其中 `df` 是频率间距（Hz），周期长度为 `1/df`；`α_L` 是拉普拉斯变换积分路径的实部（s⁻¹），与 Biot 系数无关。均匀全空间、类型 1/2/3、同组接收点全部严格位于圆柱源外时，流体场把常规 `2T` 周期延长为 `8T`，保持 `α_L`，首个周期延拓项权重成为 `image_factor^4`；位移、应变、倾斜仍用原频率网格。更小的因子对后续周期响应的抑制更强，也可能增加有限频率误差。
频率、波数相关的三个收敛标志不包含对这种混叠误差的独立估计。

排水面、材料界面或源端面的 Darcy 通量可能有 `sqrt(s)` 高频项。当前先解析计算该项对原始分段线性历史的作用，
再对余项作拉普拉斯逆变换，通过增加频率采样点数比较时间响应，不要求所有传递函数在高频时都趋于有限常数。
连续斜坡给出有限通量；真正阶跃的瞬间可以有 `1/sqrt(t)` 奇性，节点返回带符号 `Inf`，
诊断中的 `singular_samples` 会指出这一情况。这是给定理想历史的数学响应，不能当成有限实测流速。
若需有限瞬时速率，应在输入中指定有物理依据的有限上升时间。


## 库仑应力输入

`mycfs stress.toml` 读取同一参考状态的应变和孔压变化。结构标识为 `schema_version=1`，根字段 `pressure_pa` 为孔压变化，单位 Pa。输入字段如下。

| 表 | 字段 |
| --- | --- |
| `[source]`、`[receiver]` | `latitude_deg`、`longitude_deg` |
| `[material]` | `shear_modulus_pa`、`poisson`、`biot_alpha` |
| `[fault]` | `strike_deg`、`dip_deg`、`rake_deg`、`friction` |
| `[strain]` | `ezz`、`err`、`ett`、`ezr`、`ert`、`etz` |

应变采用柱坐标张量分量。位置和断层角度以度表示，`biot_alpha` 为接收层 Biot 系数。总应力和库仑应力单位为 Pa，张量与符号约定见[MaoyePoro 原理](MaoyePoro原理.md#从应变计算库仑应力)。
