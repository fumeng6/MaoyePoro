# MaoyePoro 原理

MaoyePoro 的分层求解以 Rongjiang Wang 的 [POEL_2024](https://github.com/RongjiangWang/POEL_2024) 为基础，采用其基本解矩阵、稳定模态传播和波数域差分滤波方法，并结合源体积积分、时间响应及误差估计。代码与方法来源见[方法来源、署名与许可](#方法来源署名与许可)。

理论依据包括 Wang & Kümpel (2003, *Geophysics* 68, 705–717) 和 Rudnicki (1986, *Mechanics of Materials* 5, 383–393)。本页说明当前实现采用的物理定义与数值处理；数值精度结合解析解、边界与界面条件及采样加密判断，使用时关注所研究场量的实际误差。

## 物理量与模型

采用 SI：距离 m、时间 s、弹性模量和压力 Pa、位移 m、Darcy 通量速度 m/s、应变及倾斜无量纲（小角度倾斜可读为 rad）。使用圆柱坐标 `(r,θ,z)`，`θ` 为方位角，`z` 正向向下；轴对称解不随方位角改变。输入历史的正值分别表示向下加载、给定排水体积增加、注水，或正的源区孔压体积积分，负值表示相应反向过程。应变拉伸为正。

TOML 的每个材料节点按名称给出深度、剪切模量 `μ`、排水泊松比 `ν`、不排水泊松比 `νu`、Skempton 参数 `B`、水力扩散系数 `D`；Julia 对象的 `model_nodes` 按这六列排列。内部使用

```text
λ = 2μν/(1−2ν)
α = 3(νu−ν)/[(1−2ν)(1+νu)B]
qa = Qα = (1+νu)μB/[3(0.5−νu)]
dm = Qχ = D(1−νu)(0.5−ν)/[(1−ν)(0.5−νu)]
χ = dm α/qa
```

`α` 是 Biot 有效应力系数，`Q` 为 Biot 模量；`χ` 是渗透率与流体动力黏度之比，单位为 m²/(Pa·s)，用于 Darcy 定律 `v=−χ∇p`。`D` 是水力扩散系数，与内部 `dm` 含义不同。支持普通饱和岩土的参数范围：`0<B≤1`，且上式导出的 `0≤α≤1`。输入节点先检查，转换参数插值得到的每个均质子层还检查其对应的 `B=qa/[λ+2μ/3+αqa]≤1`；超过范围会报错。完全耦合准静态方程为

```text
Γ = λ tr(ε)I + 2με − αpI
∇·Γ + f = 0
Q⁻¹ ∂p/∂t + α ∂(∇·u)/∂t − χ∇²p = q
v = −χ∇p
```

无重力、惯性、塑性或非线性渗透率。材料界面上位移、总应力牵引、孔隙压、法向 Darcy 通量连续。深度重复的两行表示界面上下两侧；不同深度间参数连续线性变化，经内部参数线性插值和均质子层近似。模量/`α` 变化比例用 0.05、`dm` 用 0.25 控制分层；这些阈值控制材料离散程度，不是最终物理误差界。最后一层延伸至无限深。

当全模型 `νu=ν` 且采用力源时，程序计算无耦合的排水弹性响应，孔压与 Darcy 通量均为零。混合零/非零耦合层和零耦合流体源不在支持范围。

## 源、边界和历史

| 源类型 `istype` | 历史函数单位和含义 | 几何限制 |
| --- | --- | --- |
| 0 | 地表或地下施加的竖向总力 N | 半径正；可为水平圆盘面源或有限圆柱源 |
| 1 | 已知排水体积应变在源区的积分 `Vd=∫εd,vol dV`，m³ | 半径和轴向长度均正；计算该排水体积变化引起的孔压与附加变形 |
| 2 | 每秒注入的流体体积 m³/s，负值为抽水 | 半径和轴向长度均正 |
| 3 | 源区平均孔压乘源体积，Pa·m³ = N·m | 半径和轴向长度均正；按各频率下的源区平均孔压响应调整源幅度 |

类型 1 的输入键为 `matrix_volume`，上游名称为 `local matrix volume change`。其输入是预先求得的排水体积应变 `εd,vol` 在源区的积分 `Vd`，不是主动膨胀或受压空腔的完整力学源。代码以等效流体源 `qeq=−α dVd/dt` 计算孔压及其附加位移、应变和应力，输出不包含原排水位移、应变和应力。若采用方程分解求完整响应，须另外叠加已知排水场；竖向外载问题也可直接使用源 0 求耦合响应。这个定义来自固定上游版本[示例 3 的 SOURCE PARAMETERS B 注释](https://github.com/RongjiangWang/POEL_2024/blob/5361220e0bea8e4876151c3fd79c523c83842ffd/InputFile/poel2024_example_3.inp#L50-L57)：先算排水体积应变，再以其乘源体积定义输入。

类型 3 给定 `M(t)=∫源体积 p dV`，可由平均孔压乘源体积得到；上游称它为 `injection moment`，输入键为 `injection_moment`。这个程序专用名称与地震矩无关，也不表示直接指定某个井壁点的压力。

源内部必须位于同一均质子层，端点可接触材料界面，但不能跨层。轴向分布均匀。径向分布的 Hankel 变换因子为 `8J₂(kr₀)/(kr₀)²`，对应归一化径向权 `w(ρ)=2[1−(ρ/r₀)²]/(πr₀²)`，`0≤ρ≤r₀`，不是均匀圆盘分布。源半径为 `r₀=sradius`，响应积分与源区孔压归一化使用同一物理源半径；改变接收网格只改变数值采样，不改变源分布。`effective_radius` 记录该半径，单位为 m。

源区孔压体积积分与接收点场的积分分别检查。前者使用低波数端点修正，并实际减半 `dk`；只有高波数尾部相对增量不超过 `min(0.001,accuracy/8)`、相邻采样结果差不超过 `accuracy/4` 时，源归一化积分才报告收敛。它用于类型 3 的源强归一化，以及类型 2/3 的等效输出；这仍是数值加密比较，不是任意参数下的严格误差界。

| `isurfcon` | 条件 |
| --- | --- |
| 0 | 无自由面：上行、下行均衰减的全空间；多层模型上方按首层向上延伸 |
| 1 | 自由排水面：总法向/剪应力为零，`p=0` |
| 2 | 不排水自由面：总法向/剪应力为零，`∂p/∂z=0` |

表中的零牵引适用于无外载地表。源0若为 `zstop=zsbtm=0` 的地表盘载荷，
表面法向牵引是 `Γzz=−F(t) w(r)`，不是零；剪牵引仍为零，排水/封闭条件保持。
源面取从介质内部、即深度增大一侧趋近该面的极限值，不能把虚拟上侧与介质内侧的法向应力平均。

源历史第一时刻必须为 0，时刻非递减。相同时刻的相邻点表示阶跃，其他点间为线性变化。第一值非零表示零时刻加载阶跃；TOML、外部 CSV 和 Julia 对象保留用户给出的节点，由时间历史计算直接处理首值，不补入、排序或删除节点。历史函数按真实时刻分解为阶跃和斜坡，按各自非负延迟叠加；类型 1 通过在频域乘 `s` 表示对给定排水体积的时间导数。尚未开始的加载严格没有响应，包括输出窗口内及窗口后的加载。无历史阶跃时初始场为零；有阶跃时保留相应的瞬时响应，以及理想脉冲等不能用普通有限点值表示的数学奇性。

## 输出

数组顺序固定为 `(time, distance, depth, component)`，分量顺序为 `uz, ur, ezz, err, ett, ezr, tlt, pp, dvz, dvr`。`ezr` 是张量剪应变，不是工程剪应变。`tlt=−∂ur/∂z`，正值表示井中倾斜仪上端远离源；它一般不等于 `−ezr`，但均匀全空间的势位移点注入解满足该关系。`dvz,dvr` 是 Darcy 通量速度（体积流量/总横截面积），不是除以孔隙率的孔隙内速度。输出应变并非应力；总应力应按 `Γ=λ trε I+2με−αpI` 重建。

JLD2 完整保存 Float64 场量、坐标及物理和数值元数据；每个分量独立存储，以便选择读取。按需导出的文本时序按深度外层、距离内层排列，各列名携带 Z/R 索引；快照逐深度、逐距离写十个量。精确保存时刻直接返回原值，避免 `0*Inf` 污染相邻有限节点；其他时刻使用相邻有限时间样点的线性插值，包括第一时间间隔。非有限端点之间，或跨源历史实际跳变、斜率转折的时间区间，明确拒绝插值；这也适用于按坐标查询，以免后处理制造提前响应。文本仅用于交换和分析，计算及归档保持 Float64。

## 数值计算规则

分层计算采用随传播距离衰减的模态，并对基向量归一化，控制层间传播时的数值尺度。近重根分支同时检查相对波数差及其与传播步长的乘积，避免等价表达式中的指数溢出；低频差商利用数学恒等式和 `expm1` 减少相近数相减的误差。均匀全空间流体源沿有限井段的深度积分采用解析表达式。

空间积分按物理条件和计算位置选择，源分布及单位不变：

| 条件 | 空间积分与检查 |
| --- | --- |
| 均匀全空间流体源，接收点到圆柱源体的最短距离不小于 `max(源半径,源长/2)` | 对源体积积分点源 Green 函数，计算全部十场；比较 4/8/16/32/64 阶 Gauss 结果 |
| 均匀全空间类型 1/2/3 流体源，同组接收点全部严格位于源外但不满足上述距离条件 | 孔压及 Darcy 通量用非振荡源积分，变形场保留 Hankel 积分，分别检查误差 |
| 分层或半空间流体源 | 均匀直接场与边界修正分别积分，各分配一半绝对容差；源材料直接场在距离及成本合适时用源体积积分 |
| 快速衰减且均匀波数网格已很细的边界修正 | 在适用几何及正实部拉普拉斯频率下尝试映射自适应 Gauss；比较局部 8/16 点求积及两个映射尺度，不满足容差时用原积分 |
| 源内、近源或上述方法不适用的位置 | 保留带端点修正、微分滤波、范围扩展和 dk 加密的 Hankel 积分 |
| 全模型纯弹性力源 | 静态空间响应乘真实荷载历史；均匀半空间地表抛物力盘的地表场采用 Boussinesq 解析积分 |

分层直接场仍使用实际模型的同一个源向量及归一化。参考通量先按源材料转换为孔压梯度，再按实际接收层材料转换为物理 Darcy 通量，表面投影与原谱核保持一致。成本选择及诊断字段见[使用说明](输入输出格式.md#数值诊断)。相邻 Gauss 阶数、映射尺度、波数范围及间距差均为误差估计，不是严格上界；达到容量不表示收敛。

Ogata、数字线性滤波和 FFTLog 尚未作为默认求解路径。不同源、位置和弱场对它们有不同精度要求，固定数百节点不能替代实际误差检查。相关方法来源包括 [Ogata (2005)](https://doi.org/10.2977/PRIMS/1145474602)、[Key (2012)](https://doi.org/10.1190/geo2011-0237.1) 和 [Werthmüller 等 (2019)](https://doi.org/10.1190/GEO2018-0069.1)。

时间响应按分段线性源历史计算。阶跃、斜坡及高频渐近项的具体处理见下文。等效量仅在 `compute_equivalent=true` 且源类型支持时计算，其单位由输入的物理源决定。

源 1 对应的等效流体注入率为 `−α dVd/dt`：恒定排水体积区间内为零，线性斜坡区间为 `−α×斜率`；由它得到的是孔压扩散和附加力学场。
内部历史节点取右侧速率，输出窗口最后一刻取左侧速率；阶跃对应的脉冲体积另存于等效源诊断，不能以节点速率代替。

多线程频率任务只共享源积分的只读几何与权重，首次构造时同步；模态传播状态和源压力归一化权重由各任务独立保存。等效源的频率计算遵守同一并行设置，精度和收敛判断不随线程数放宽。

## 从应变计算库仑应力

`coulomb_from_strain` 必须提供接收点所在层的 Biot 系数 `alpha`。它先用应变计算骨架弹性应力 `S=λ trε I+2με`，再构造耦合总应力 `Γ=S−αpI`，用总应力计算 `ΔCFS=τ+f(σn+p)`，拉应力为正。返回的 `matrix_stress` 和 `total_stress` 分别为北、东、下坐标中的 `S` 和 `Γ`，`convention=:total_stress_plus_pressure`。

对类型 1，按其输出重建的应力仍是附加场的总应力；分析原外载引起的完整库仑应力变化，还须叠加已知排水应力。

也可自行构造 `Γ` 后调用 `coulomb_stress(Γ,p,f,strike,dip,rake)`；两种入口计算相同的物理量，等价于用骨架弹性应力计算 `τ+f[σmatrix,n+(1−α)p]`。独立应力输入采用命名字段 TOML，其中 `material.biot_alpha` 必须显式给出接收层的 Biot 系数，不默认取值。最优面由应力极值对应的特征向量确定；若主应力重复，最优方向不唯一，静水应力时方向未定义。

## 界面、积分与拉普拉斯逆变换

拉普拉斯逆变换由复频率域响应求时间响应。计算采用以下物理约束及数值处理，其独立依据和已执行精度见[数值核对](MaoyePoro原理.md#数值精度)。

1. **跨层法向通量。** 层内状态向量使用辅助量 `q_aux=q_z+αs u_z`，其中 `q_z` 是物理 Darcy 通量的拉普拉斯变换，`s` 是拉普拉斯变量。
   α 不同的两层通过位移及物理通量连续条件连接。向下跨界面时，辅助量加 `(α下−α上)s u_z`，
   向上时在临时副本中作逆映射，再用上层基底传播；界面接收点保存从深度增大一侧趋近界面的极限值。
   这种转换使界面两侧连续的量为物理 Darcy 通量 `q_z`。
2. **力源的零波数端点。** 力源垂向位移的 Hankel 被积函数在 `k→0` 一般有非零极限。
   常规积分使用前六个完整被积函数样点作 Euler–Maclaurin 端点修正，处理 `f(0)/2`、一阶、三阶、五阶导数项。
   埋藏零厚度力盘的零阶积分直接对 `[0,6dk]` 作六段 16/32 点 Gauss 求积，把原端点规则移到 `6dk` 处；两规则差进入空间误差估计，仍由实际 dk 减半检查精度。
   不能将这一有限 dk 外推解释为任意分层下的精确零波数公式。
3. **边界条件及对称性确定的零值。** 在积分相对判据之前使用自由面零剪牵引、排水面 `p=0`、封闭面 `dp/dz=0`。
   仅对单均质层全空间流体源、精确源中平面，使用奇对称的 `uz=ezr=dp/dz=0`。
   不推广到半空间、物性分层或近似对称。埋于同一材料内部的力盘，在全部层间传播因子已下溢为零的高波数点，直接计算均匀全空间源平面响应及其反对称零值，省去已解耦的矩阵求解；该分支仅保证返回场量，其他传播路径保留原始状态供残差检查。
4. **抑制时间周期延拓造成的响应混叠。** 离散频率的拉普拉斯逆变换相当于对时间响应作周期延拓，后续周期的响应可能叠入所求时间窗。
   用 `image_factor=exp(−α_L/df)` 控制后续周期响应的衰减，默认值为 0.001。
   `df` 是频率间距（Hz），周期长度为 `1/df`；`α_L=−df log(image_factor)` 是拉普拉斯逆变换积分路径的实部（s⁻¹），与 Biot 系数无关。
   常规场响应周期为 `2T`。均匀全空间的类型 1/2/3 源、同组接收点全部严格位于圆柱源外时，孔压和 Darcy 通量把周期延至 `8T`、保持原 `α_L`，首个周期延拓项权重由 `image_factor` 降为 `image_factor^4`；力学场保留原频率网格。
   更小的输入因子抑制后续周期响应更强，也可能放大有限频率误差；其影响可在固定物理模型及其他数值设置后，通过比较不同因子的计算结果判断。

排水面、某些材料界面及源端面在突然加载下可形成薄扩散层，通量传递函数可随 `sqrt(s)` 增长，
对应阶跃响应的 `1/sqrt(t)` 型起始奇性。因此不能普遍假定所有场量的传递函数在高频时都趋于有限常数。
将高频项的解析时域响应与余项的数值拉普拉斯逆变换结合，按真实加载时刻计算响应：

`G(s) = a1*s + ah*sqrt(s) + a0 + R(s)`。

前三项对历史 `h(t)` 的作用分别为一阶导数、半阶导数及原函数值，均按输入历史解析计算。
对余项，分别将阶跃对应的 `R(s)/s` 和有限斜坡对应的 `R(s)*(1-exp(-s*T))/s^2` 作拉普拉斯逆变换，
阶跃响应和斜坡响应分别扣除数值逆变换在零时刻的值，然后按每个真实加载时刻平移叠加；非正延迟的余项严格为零。
有限斜坡对应 `min(t,T)`，所需延迟都不超过窗口T，故与实际斜坡在当前区间完全等价。
这种有限时长斜坡控制周期延拓造成的混叠，同时按真实起点叠加，保持加载的因果性。

源 2 的响应随 `s` 增大而衰减，重构中的直接及增长项系数为零，不再进行这些系数的无效拟合。其他源类型只在相应物理边界或界面允许时引入 `sqrt(s)` 项，不对每个场量任意拟合增长项。拟合中的衰减负幂只用于外推前导系数，默认不作一般性解析扣除。
高频系数分别在两组不同的正实拉普拉斯变量取值范围内估计，并比较两组系数造成的实际时序差，以检查高频近似对取样范围的敏感性。
因果性处理及零时刻数值校正不能消除正时间段的有限频率误差或时间周期延拓造成的混叠误差。

真正阶跃处的半阶导数可能为带符号 `Inf`，`s`项的 Dirac 脉冲权重另行保存。连续斜坡的半阶导数有限，
不能以有限节点峰值人为取代理想阶跃的奇性。数值反演路径实际加倍频率数量；Hankel 路径实际减半波数间距，分别按每个接收点/分量的全时段峰值归一检查，阈值为输入 `accuracy/4`。源体积路径通过求积阶数差检查空间误差，纯弹性解析路径不引入无效频率反演。

半阶导数和半阶积分直接对原始分段线性历史计算。端点权重采用代数等价形式，减少相近平方根及跨斜坡大数相减造成的舍入误差，以计算短脉冲结束后的微弱尾部响应。

加载因果性及独立物理参考的核对范围见[数值核对](MaoyePoro原理.md#数值精度)。
一般多层的这些收敛比较及边界物理条件仍不等于拥有每条时序的独立解析真值或严格绝对误差界。

## 独立科学依据及结论边界

均匀全空间恒定点注入解使用 Rudnicki (1986) pp.386–387 的式(16)–(26)及 Wang & Kümpel (2003) 正文第2–3页式(17)–(20)：`p=q erfc[R/(2√Dt)]/(4πχR)`，位移的解析径向函数可直接求导得到应变、倾斜和 Darcy 通量。对该解按轴向均匀、径向上述抛物线剖面做独立空间积分，可检验有限圆柱源。该验证不调用待核 Julia 核函数。

解析解对照、不同数值方法的比较、边界及界面条件检查分别提供不同证据。真实场地中的参数与模型近似需要结合观测依据判断。

## 数值精度

均匀全空间有限井段注水可用点注入解析解按相同源分布积分作参考。材料为 `μ=1e10 Pa, ν=0.25, νu=0.35, B=0.5, D=1 m²/s`，源半径 100 m、深度 900–1100 m，注入率在零时刻阶跃至 0.01 m³/s。`cases/constant_injection.toml` 的六个接收位置、65 个时刻中，七个力学场分量的最大参考峰值归一误差约为 0.2271%。误差对每个物理量分别计算，弱场还应检查绝对误差。

每次研究计算应查看 `diagnostics` 中的空间采样、空间求积和频率判据。材料参数误差、地层近似和后处理插值误差需要单独评估。字段定义见[输入输出格式](输入输出格式.md#数值诊断)。
