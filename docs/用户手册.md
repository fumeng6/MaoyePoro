# MaoyePoro 用户手册

MaoyePoro 计算有限井段注采、竖向荷载及给定排水体积变化引起的孔压、位移、应变、倾斜和 Darcy 通量。输入参数采用 SI 单位，深度向下为正。

分层孔隙弹性求解以 Rongjiang Wang 的 POEL 实现为基础，物理定义、方法来源及 GPL-3.0 许可见[MaoyePoro 原理](MaoyePoro原理.md)。`cases/` 提供恒定注水、延迟注水与停井、两层介质注水三份合成输入。

<a id="scope"></a>
## 物理模型

采用轴对称、小变形、线性、准静态 Biot 孔隙弹性理论。介质可均匀、水平分层，或沿深度变化后离散为均质子层。顶部可为全空间、自由排水面或封闭自由面。

源区沿深度均匀，径向为抛物分布。井段注采使用有限圆柱，竖向力也可使用水平圆盘。完整源区须位于一个实际均质子层内。模型和符号的详细定义见[科学约定](MaoyePoro原理.md)。

<a id="setup"></a>
## 环境

可执行程序自带 Julia 运行时与依赖。Windows 解压后运行 `install.cmd`，Linux 运行 `sh install.sh`，在终端使用 `myporo` 与 `mycfs`。安装步骤见下节，源码构建见[构建可执行程序](#build)。

使用 Julia API 时，推荐 Julia 1.13.2。在项目根目录准备依赖。

```powershell
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --threads=4 --project=.
```

在 Julia 会话中设置小矩阵运算使用单线程 BLAS。

```julia
using MaoyePoro, LinearAlgebra
BLAS.set_num_threads(1)
```

独立频率可使用多个 Julia 线程。`parallel=false` 或命令行 `--serial` 关闭频率并行。线程数在 Julia 进程启动时指定。各任务独占传播状态，共享源积分的只读坐标和权重。

## 安装可执行程序

| 下载包 | 运行环境 |
| --- | --- |
| `MaoyePoro-v1.0.0-Windows-x64.zip` | Windows 10/11，64 位 x86 处理器 |
| `MaoyePoro-v1.0.0-Linux-x86_64.tar.gz` | Linux x86_64，glibc 2.34 或更新；在 Ubuntu 24.04 中编译和运行 |

Linux 包的 ELF 文件所需最高 GLIBC 符号版本为 2.34，实际运行核对在 Ubuntu 24.04 完成。该包不适用于 ARM、Alpine/musl 或较旧的 glibc 环境；这些系统需在目标环境从源码构建。两个包均使用通用 CPU 编译目标，不依赖构建机的专有指令。预编译包面向 Windows x64 和 Linux x86_64；其他平台需在相应环境中构建。

### Windows

将压缩包解压到固定目录，双击 `install.cmd`，或在该目录的 PowerShell 运行 `./install.ps1`。脚本把包的根目录加入当前用户 PATH，无需管理员权限。重新打开终端后可从任意工作目录运行：

```powershell
myporo --version
myporo --help
myporo --template case.toml
myporo case.toml --check
myporo case.toml --output results\case
mycfs stress.toml
```

包的根目录只提供两个命令启动文件，随包的 `bin/julia.exe` 不会被加入全局 PATH。请保留解压目录；移动后在新位置重新运行安装脚本，并从用户 PATH 删除原位置。

也可不安装命令，在解压目录直接执行：

```powershell
.\bin\myporo.exe cases\constant_injection.toml --check
.\bin\myporo.exe cases\constant_injection.toml --output results\constant_injection --format both --julia-args -t4
.\bin\mycfs.exe stress.toml
```

```sh
tar -xzf MaoyePoro-v1.0.0-Linux-x86_64.tar.gz
cd MaoyePoro-v1.0.0-Linux-x86_64
sh install.sh
```

安装脚本把两个程序链接到当前用户的 `~/.local/bin`。如果该目录尚不在 PATH，将下面一行加入所用 shell 的配置文件（例如 Bash 的 `~/.bashrc`），然后重新打开终端：


## 计算与检查

在项目根目录运行恒定注水情形。

```powershell
julia --threads=4 --project=. maoyeporo.jl cases/constant_injection.toml --check
julia --threads=4 --project=. maoyeporo.jl cases/constant_injection.toml --output results/constant_injection --format both
```

可执行程序使用相同输入。

```sh
myporo cases/constant_injection.toml --check
myporo cases/constant_injection.toml --output results/constant_injection --format both --julia-args -t4
```

该问题为均匀全空间中深度 900–1100 m、半径 100 m 的井段恒定注水，流量 0.01 m³/s。接收位置为 r=300/2000 m 与 z=500/1000/1500 m 的六个组合，计算到 100000 s，保存 65 个时刻。

检查命令读取输入、材料分层与深度网格。求解完成后，先查看 `simulation_info.txt` 或归档读回结果的 `status`；需要逐组误差与采样细节时，运行命令加上 `--diagnostics`，查看独立的 `diagnostics.txt`。

<a id="input"></a>
## 输入配置

生成带中文注释的待填写配置。

```sh
myporo --template case.toml
```

必填标量用空字符串留空，填数值时去掉引号。必填数组用空数组留空。填写后运行 `myporo case.toml --check`。

| 配置部分 | 内容 |
| --- | --- |
| `[source]` | 物理过程、源区几何与完整时间历史 |
| `[receivers]` | 径向距离和深度数组 |
| `[time]` | 输出时间窗与保存样点数 |
| `[medium]`、`[[medium.nodes]]` | 顶部条件和材料节点 |
| `[numerics]` | 数值精度 |
| `[output]` | 文本场量、快照、等效量与诊断开关 |

模拟 TOML 使用 `schema_version=2`。该字段记录文件结构，独立于程序版本号。

| `source.kind` | `values` 的物理量 | 单位 |
| --- | --- | --- |
| `injection_rate` | 流体注入率，负值为抽水 | m³/s |
| `force` | 向下为正的竖向总力 | N |
| `matrix_volume` | 给定排水体积应变在源区的积分 | m³ |
| `injection_moment` | 源区平均孔压乘源体积 | Pa·m³ |

`matrix_volume` 输出由孔压引起的附加变形，完整外载响应需要叠加给定的排水场。`injection_moment` 给定源区平均孔压，并可计算对应等效注入率。

<a id="history"></a>
## 源历史

`times_s` 与 `values` 等长，首时刻为零。相邻不同时间之间线性变化，重复时刻表示阶跃。非零首值表示零时刻加载。最后一个值保持到计算结束。窗外节点可保留跨越输出窗口的斜坡。

延迟注水与停井的物理对照使用下列历史。

```toml
times_s = [0.0, 25000.0, 25000.0, 50000.0, 50000.0, 100000.0]
values = [0.0, 0.0, 0.01, 0.01, 0.0, 0.0]
```

注水在 25000 s 开始，50000 s 停止，累计注入 250 m³。停井后的响应由已有压力扰动继续扩散。

<a id="long-history"></a>
### 长历史 CSV

长历史可由 `[source]` 中的 `history_file` 引用。用文件引用时删除内嵌的 `times_s` 和 `values`。CSV 首行为 `time_s,value`，每行一对时间与源值。

```csv
time_s,value
0,0
25000,0
25000,0.01
50000,0.01
50000,0
100000,0
```

相对路径以 TOML 所在目录为准。读取保留重复节点、首值及窗外节点。流量值的单位为 m³/s，累计注入体积由速率积分得到。

<a id="medium"></a>
## 介质与接收点

| 材料字段 | 含义 |
| --- | --- |
| `depth_m` | 节点深度，m，首节点为零 |
| `shear_modulus_pa` | 剪切模量，Pa |
| `poisson` | 排水泊松比 |
| `undrained_poisson` | 不排水泊松比 |
| `skempton` | Skempton B |
| `diffusivity_m2_s` | 水力扩散系数，m²/s |

材料突变界面用相同深度的两个节点表示上下两侧。不同深度间的物性按梯度离散为均质子层。末节点以下无限延伸。材料参数应满足 Biot 系数和 Skempton B 的物理条件，程序在输入和离散后检查。

顶部条件使用 `fullspace`、`drained` 或 `sealed`。全空间中的 z=0 是深度参考。排水面孔压为零，封闭面法向 Darcy 通量为零。

`radii_m` 与 `depths_m` 均为非负、有序数组，计算全部 r×z 组合。时间样点数由 `[time].samples` 指定，包含零时刻和终时。

<a id="read-results"></a>
## 结果读取

默认只输出 `result.jld2`，保存全部物理场、坐标单位、输入、实际模型、求解设置和简短计算状态。`--format both` 同时写出文本时序，`--format text` 导出文本；文本格式还包含说明坐标、单位和状态的 `simulation_info.txt`。详细数值诊断通过 `--diagnostics` 或 `[output] diagnostics = true` 单独保存为 `diagnostics.txt`。

```julia
using MaoyePoro
result = load_result("results/constant_injection/result.jld2")
pressure = field(result, :pp)
pressure[:,1,1]              # 第一半径、第一深度的孔压时序，Pa
result.time                 # s
result.status               # 场量/等效源收敛状态及奇异样点标志
result.equivalent_impulses   # 若计算等效源，保留瞬时脉冲的时刻 s、体积 m³
```

数组顺序为 time × radius × depth × component。`field` 返回结果数组的视图，需要独立副本时用 `copy`。

```julia
q = sample_field(result, :pp; r=300.0, z=500.0, tspan=(20000.0,40000.0))
q.time
q.data
s = snapshot(result, 50000.0)
```

按坐标查询默认使用保存节点。显式 `method=:linear` 可插值，需遵守材料界面、源区边界和历史变化时刻的限制。配对点、平面、曲面及张量旋转见[场查询](用户手册.md#field-query)。

<a id="field-query"></a>
## 按物理坐标查询

`receivers` 定义的是**计算采样网格**。对轴对称、水平分层问题，只需计算一个穿过源轴线的竖直剖面（r–z 子午面）；程序计算各半径与各深度的全部组合，并复用径向积分结果。
用户分析则可独立选择几何。`sample_field` 和 `strain_tensor` 接收完整结果或 JLD2 路径，按物理坐标查询；路径方式只加载所需分量及查询元数据，不重新求解。

### 一个点的一段时间

先按[用户手册](用户手册.md)运行 `constant_injection.toml`，再在 Julia 中：

```julia
using MaoyePoro
path = "results/constant_injection/result.jld2"
q = sample_field(path, :ezz; r=300.0,z=500.0,tspan=(20000.0,40000.0))
q.time                  # 实际选中的保存时刻，s
q.data                  # 单点的时间向量，应变无量纲
q.unit
q.spatial_interpolated
q.time_interpolated
```

`tspan` 包含两端，但仅筛选区间内已有时间节点，不生成端点、不作时间平均。本例实际取 20312.5–39062.5 s 的 13 点。
也可用 `times=[0.0,50000.0,100000.0]` 或标量 `times=100000.0`；标量仍保留长度为 1 的时间维。`times` 与 `tspan` 互斥；都省略时取全部时间。

### 配对点与剖面

```julia
q = sample_field(path, :pp; r=[300.0,2000.0],z=[500.0,1500.0],times=100000.0)
size(q.data)             # (1,2)：一个时刻、两个配对点
```

这表示 `(300,500)`、`(2000,1500)` 两点。查询坐标遵循 Julia 广播规则，不隐式取 r×z 全组合。如需明确查询子午面网格，给一列半径和一行深度：

```julia
q = sample_field(path, :pp; r=reshape([300.0,2000.0],2,1),
    z=reshape([500.0,1500.0],1,2),times=100000.0)
size(q.data)             # (1,2,2)：time × 输入坐标阵形状
```

点集顺序可任意指定；`q.r/q.z/q.x/q.y` 返回对应坐标。场分量查询的 `data` 总是 time × 坐标形状，单点则为时间向量。

### 平面和曲面

孔压等轴对称标量只依赖 r、z。给出方位角即可取出三维空间中所选采样面上的值；源和介质仍采用原轴对称模型，也没有新增曲面边界条件。
以下为水平环形面上 12 个方位、两个半径的采样：

```julia
angles = reshape(collect(0.0:30.0:330.0),12,1)
plane = sample_field(path, :pp; r=reshape([300.0,2000.0],1,2),z=500.0,
    azimuth_deg=angles,times=100000.0)
size(plane.data)         # (1,12,2)：time × angle × radius
```

圆柱曲面也可完全命中首例的已算节点，无需插值：

```julia
cylinder = strain_tensor(path; r=300.0,z=reshape([500.0,1500.0],1,2),
    azimuth_deg=angles,tspan=(20000.0,40000.0))
size(cylinder.data)      # (3,3,13,12,2)：tensor_i × tensor_j × time × angle × depth
```

一般曲面可直接提供同形 `X,Y,Z`。坐标单位 m，**x=北、y=东、z=下**；x=y=0 为源轴，z 基准与输入相同。下面只演示显式插值的弯曲采样面：

```julia
X = repeat(reshape(collect(range(350.0,650.0;length=5)),5,1),1,4)
Y = repeat(reshape(collect(range(0.0,200.0;length=4)),1,4),5,1)
Z = 900.0 .+ 100.0 .* sin.(X ./ 500.0) .* cos.(Y ./ 400.0)
curved = sample_field(path,:ezz;x=X,y=Y,z=Z,times=50000.0,method=:linear)
size(curved.data)        # (1,5,4)
```

恒定注水例有两个半径和三个深度，这样的插值不能称作满足原 `accuracy` 的精细曲面解。科研使用应先计算足够密的网格，并比较加密后的场或查询量。
### 应变的方向与曲面法向

`sample_field` 的十个场分量采用局部柱坐标。即使给出 x/y/z，`err` 也不是任意方位上的北向应变。
`strain_tensor` 读取 `err,ett,ezz,ezr`，构成对称张量并旋转到北、东、下（NED）：

```julia
using LinearAlgebra
E = strain_tensor(path;x=180.0,y=240.0,z=500.0,times=100000.0)
epsilon = E.data[:,:,1]   # 单点、一个时刻的 3×3 NED 张量
epsilon[1,1]             # 北向正应变
epsilon[1,3]             # 北-下张量剪应变
n = [0.0,0.0,1.0]       # 示例：水平面单位法向
normal_strain = dot(n,epsilon*n)
```

`ezr` 是张量剪应变，不除以 2。曲面法向应变为该点单位法向的 nᵀεn，不应一律取 `ezz` 或 `err`；一般曲面的法向由用户几何决定。
方位角从北顺时针，以度表示。轴线上径向方向不唯一，接口约定取 0°；在轴线上有限且满足轴对称条件的解应有 `err=ett,ezr=0`，接口不强行平均或裁零。
直接查询已存场分量时保留 `Inf/NaN`。张量转换所需的四分量若非有限会报错，避免 `0*Inf` 和 `Inf−Inf` 生成虚假分量；其他无关分量的奇性不会阻止有限孔压或应变查询。

### 插值和覆盖范围

默认 `method=:exact` 只读已存坐标/时刻，不最近邻吸附、不外推。“精确”指保持保存值，仍受原求解精度约束。
明确指定 `method=:linear` 才会插值。返回标志指出是否发生空间或时间插值；`source_diagnostics` 是内存结果保留的原求解诊断，从主归档查询时为空，**不包含新增插值误差**。
插值拒绝以下情况：

- 超出原 r、z 或时间覆盖范围。
- 跨实际均质子层的深度区间，包括梯度离散后的子层；恰在材料界面上时，取从下侧材料趋近界面的值。
- 接触注水、施力或体积变化区域边界的空间区间；该规则较保守，源外不相交区域仍可查询。
- 跨流量或荷载实际跳变、斜率转折的时间区间，以免把加载后响应插到加载开始前。同一条直线上的多余节点不是新的变化点；连续斜坡恰在输出窗口末端结束时，沿用结束前的斜率。
- 所请求分量的非有限插值端点；精确节点则直接取原值。

`snapshot(result,t)` 也遵守上述时间插值限制。查询区间跨越这些变化或超出已有覆盖范围时，应重新设置计算节点。
由 x/y 求 `hypot` 可能与预设半径相差浮点末位，严格查询不自动吸附；圆周可用精确 r 加方位角，或在建计算轴时使用同一份 `hypot.(X,Y)`。

### 重新计算网格时

可以通过 `PoroelasticInput(base;r=...,zr=...)` 明确选择新计算轴，但需注意：

1. N 个配对点若分别取出所有不同半径和所有不同深度，再作全部组合，可能产生接近 N² 个计算位置；当前求解器仍按这两个计算轴求解。
2. 计算使用输入源半径 `effective_radius=sradius`，改变接收网格只改变数值采样，不改变物理源半径。
3. 查询曲面不会改变轴对称模型或施加新的曲面排水、牵引及断层边界条件。

查询实现的核对包括保存节点逐值一致、已知三线性函数插值、时间变化点及材料/源边界限制、非有限值处理，以及张量旋转前后对称性、迹（对角线之和）和范数保持不变。求解结果的物理精度范围见[数值核对](MaoyePoro原理.md#数值精度)。

<a id="fields"></a>
## 场量

| 字段 | 物理量 | 单位 |
| --- | --- | --- |
| `uz`、`ur` | 垂向、径向位移 | m |
| `ezz`、`err`、`ett`、`ezr` | 正应变与张量剪应变 | 1 |
| `tlt` | 径向倾斜 | rad |
| `pp` | 孔压变化 | Pa |
| `dvz`、`dvr` | 垂向、径向 Darcy 通量 | m/s |

Darcy 通量为单位总横截面积上的流体体积流率。垂向位移向下为正。应变张量用北、东、下坐标时调用 `strain_tensor`，方向定义见科学约定。

<a id="cases"></a>
## 三份合成输入

| 情形 | 核对目标 |
| --- | --- |
| 恒定井段注水 | 有限源扩散、十场独立解析参考、弱孔压与 Darcy 通量 |
| 延迟注水与停井 | 加载前响应、停井后的持续扩散、真实跳变时刻 |
| 两层介质注水 | 材料界面孔压与法向通量的连续条件 |

这三份输入位于 `cases/`。它们分别说明有限圆柱注入、停井后的持续响应和物性反差界面的设置。实际研究时复制接近目标问题的输入，并按物理条件修改参数。

<a id="accuracy"></a>
## 精度与诊断

`accuracy` 默认 0.05，各分项采样目标为 `accuracy/4`。诊断按每个接收点组记录。

默认始终检查收敛，保留科学警告，并在主结果的 `status` 中记录简短状态。开启 `myporo case.toml --diagnostics`，或在 TOML 的 `[output]` 下写入 `diagnostics = true`，会额外输出 `diagnostics.txt` 并显示详细进度；加上 `--quiet` 可关闭进度而继续保存报告。开关只控制详细信息的保存和展示，不改变物理计算、精度和采样上限。

Julia 中可用 `run_simulation(path; diagnostics=true)`，也可对 `solve` 返回的内存结果调用 `write_outputs(result; output_dir="results/run", diagnostics=true)`。内存结果始终保留完整诊断；主归档只保存 `status`，`load_result` 读回后不含逐组诊断记录。

| 字段 | 含义 |
| --- | --- |
| `sampling_converged` | 空间采样加密比较满足判据 |
| `wavenumber_converged` | 空间求积与高频系数所需的积分满足判据 |
| `frequency_converged` | 频率加密与高频系数组合满足判据 |
| `source_normalization_converged` | 源区孔压归一化积分满足判据 |
| `singular_samples` | 存在理想阶跃产生的无穷样点 |

Hankel 积分检查波数范围和间距，源体积积分比较 Gauss 阶数。接近零的场量应比较绝对误差。研究关注的分量应在相同物理模型下作加密比较，弱扩散信号还需检查时间周期延拓误差。完整定义见[使用说明](输入输出格式.md#数值诊断)和[科学约定](MaoyePoro原理.md)。

理想阶跃可能产生 `t^(−1/2)` 通量或 Dirac 流体脉冲。需要有限上升时间时，应把实验或场地对应的上升过程写入源历史。若计算等效源，脉冲时刻和体积始终保存在 `equivalent_impulses` 中，文本格式在 `simulation_info.txt` 中记录；这部分是物理结果，不受诊断开关影响。

<a id="julia-workflow"></a>
## Julia 计算

```julia
using MaoyePoro, LinearAlgebra
BLAS.set_num_threads(1)
base = read_input("cases/constant_injection.toml")
result = solve(base)
save_result("results/run.jld2", result)
write_outputs(result; output_dir="results/run_text", format=:text)
```

参数研究使用复制构造，并为每组设置独立输出路径。

```julia
for (name,rate) in (("q001",0.01),("q002",0.02))
    input = PoroelasticInput(base; sinj0=[0.0,rate,rate])
    result = solve(input)
    save_result(joinpath("results",name*".jld2"),result)
end
```

复制构造复制数组并校验参数。`solve` 返回内存结果，`run_simulation` 求解并写出结果。每次研究计算先检查 `status`，需要核查具体误差时保存详细诊断。

<a id="coulomb"></a>
## 库仑应力

由同一参考状态的应变、孔压和接收层材料构造总应力，再投影到给定断层面。使用张量剪应变，接收层 Biot 系数由 `alpha` 显式给出。

```julia
out = coulomb_from_strain(
    lat0=30.0, lon0=103.0, latr=30.002, lonr=103.003,
    mu=1e10, nu=0.25, alpha=0.8,
    strain=(1e-6,-2e-6,0.5e-6,0.3e-6,0.0,0.0),
    pressure=1000.0, friction=0.6, strike=30.0, dip=60.0, rake=90.0)
out.total_stress
out.receiver.cfs
```

总应力为 `λ tr(ε)I+2με−αpI`，拉应力为正。库仑应力变化为剪应力加 `friction*(法向总应力+孔压)`。已有总应力张量可直接调用 `coulomb_stress`。文件入口 `mycfs stress.toml` 的命名字段见[使用说明](输入输出格式.md)。

<a id="build"></a>
## 构建可执行程序

构建使用 Julia 1.13.2 和 PackageCompiler 2.4.5 的 `create_app`，构建环境位于独立的 `build` 目录。先在项目根目录安装运行依赖和构建依赖：

```sh
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=build -e 'using Pkg; Pkg.instantiate()'
```

Windows PowerShell：

```powershell
$env:JULIA_CC = $null
$env:JULIA_IMAGE_THREADS = '2'
julia --threads=2 --project=build build\build_app.jl
```

Windows 使用 PackageCompiler 配置的 MinGW GCC 工具链。构建脚本为两个入口内嵌 UTF-8 进程声明，使中文安装路径能正确传递给运行时。

Linux 需可用的 GCC 工具链，在 Linux 环境内构建：

```sh
JULIA_IMAGE_THREADS=2 julia --threads=2 --project=build build/build_app.jl
```

默认生成 `local_archive/builds/MaoyePoro-Windows-x64` 或 `local_archive/builds/MaoyePoro-Linux-x86_64`。目标目录须尚不存在，也可在命令末尾指定新的输出目录。Windows 和 Linux 必须分别编译，不能把 Windows 包直接用于 Linux。

PackageCompiler 在单独的 Julia 子进程中执行预热算例，该子进程不自动继承构建命令的 `--threads`。构建脚本通过 `JULIA_NUM_THREADS` 为它显式配置至少两个线程，预热脚本也会检查实际线程数，使并行求解路径实际参与预热。

构建采用 `cpu_target="generic"`，保留完整 Julia 运行时及标准库，打包 FFTW、特殊函数和 JLD2 实际需要的动态库。未使用的可选 MKL 后端不随包提供。若要适配较旧 Linux，应在相应的较旧 glibc 构建环境重新编译。

`juliac --trim` 需要编译器能静态确定入口可达的调用；本项目的通用 TOML/JLD2 输入输出仍采用完整应用镜像，用于支持 TOML 配置和 JLD2 归档。

参考：[PackageCompiler 应用构建](https://julialang.github.io/PackageCompiler.jl/stable/apps.html)、[JuliaC](https://github.com/JuliaLang/JuliaC.jl)。
